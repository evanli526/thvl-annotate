# 从下载到开始标注

你的任务是完整观看视频，核对机器候选，只保留有明确依据的风险片段。每个片段填写**起止时间、标签、模态和一句简短理由**。机器理由在旁边供参考，由你独立作判断。

## 1. 安装并启动

准备 Git、Python 3.10+ 和 Chrome 或 Edge。不需要 GPU、模型或第三方 Python 库。视频保存在云端，按需联网播放，不会事先下载整个数据集。

在终端检查 `git --version` 和 `python --version`。没有相应命令时，请先安装 Git 和 Python；Windows 安装 Python 时勾选 Add Python to PATH。macOS/Linux 通常把下文的 `python` 换成 `python3`。

```bash
git clone https://github.com/evanli526/thvl-annotate.git
cd thvl-annotate
python annotate.py
```

输入负责人分配的 `A1`、`A2` 或 `EXPERT`。程序会打开浏览器，也会打印完整的本地地址，例如 `http://127.0.0.1:8800/?annotator=A1`。无需网站账号密码。不要直接双击 HTML 文件；请保持终端运行。

已有旧版时，确认保存后在终端按 Ctrl+C 停止服务，然后执行：

```bash
git pull --ff-only
python annotate.py --annotator A1
```

换成自己的代号。重新启动后刷新网页；若仍显示旧版，可用 Ctrl+Shift+R 强制刷新。**不要删除 `.annotation-work/`**，它保存了人工结果。更新程序不会改变本轮任务版本；已有人工理由会保留，新机器草稿的人工理由留空。

## 2. 认识以视频为主的工作台

建议使用电脑浏览器，窗口宽度至少 1280 像素。

| 区域 | 用途 |
|---|---|
| 最左侧视频列表 | 搜索编号、查看进度、切换视频；列表单独滚动 |
| 主区域的大播放器和时间轴 | 完整看视频、调倍速、定位片段边界；占据页面主要空间 |
| 播放器下方参考标签 | 默认收起，点击“机器候选”“转写”“补查提示”展开，再次点击收起；专家还可看“两人对比” |
| 右侧“你的标注” | 编辑选中片段的时间、标签、模态与简短理由 |
| 编辑栏下方的“机器理由” | 展示该片段的原始机器理由，自动换行，长文可独立滚动 |
| 右下方片段列表 | 选择片段；“待填写”表示还有必要信息未填，并非新风险类别 |
| 顶部保存提示 | 修改后自动保存；切换前等待保存成功，无需填写视频进度 |

视频和紧凑编辑区保持在同一屏内，没有底部视频进度栏。列表或参考内容较长时，在对应区域滚动；较小屏幕或放大显示时，编辑区也可独立滚动。

机器候选与人工结果是两份记录。**删除人工片段不会删除原机器参考。** 机器置信度、`ok` 或 `partial` 仅描述机器输出，不能当作人工判断。没有机器候选也需要完整观看。

## 3. 标注员：每条视频按顺序操作

### 完整观看，核对片段

先看完整视频并听音，了解上下文。再从右下方列表选择候选，点击“本段”或“循环本段”核对。机器标签和时间是草稿起点；人工理由由你填写，不会自动复制机器原文。

- **标签成立**：校准时间，核对标签与模态，自己写一句理由。
- **部分标签成立**：删掉没有依据的标签，保留成立标签。
- **整段没有充分依据**：删除该片段。不要用“证据不足”作为保留风险标签的理由。
- **发现漏报**：暂停在开始位置，点击“新建片段”，补齐时间、标签、模态和理由。
- **同一事件被重复切碎**：确实连续才合并。若中间存在明显正常间隔，应分段保留。

“补查提示”是机器遗漏、失败或不确定区间的定位参考。回看后，成立就补标，不成立就不纳入人工片段；无需逐项选择处理状态。确认完成前仍须看完视频，不能只看机器框出的部分。

### 时间填写“分:秒”

| 实际时间 | 填写示例 |
|---|---|
| 1 分 35 秒 | `01:35` |
| 1 分 39.5 秒 | `01:39.5` |
| 9 秒 | `00:09` |
| 1 小时 2 分 3 秒 | `62:03` |

也可以用起终点下方的“取当前时间”，将播放头作为边界。起点必须早于终点，终点不能超过视频时长。`01:99`、`1.35` 等格式不会保存为时间；按页面提示改正。界面显示到 0.1 秒；内部文件仍以秒存储，与旧结果兼容。

可使用 0.5× 慢放，或 1.25/1.5/2/3× 快放；按 ←/→ 前后移动 1 秒，Shift+←/→ 移动 5 秒，`,`/`.` 微调 0.1 秒。倍速不改变标注时间。3× 适合定位，不宜用于核实难懂语音和快速动作。

### 标签、模态与理由

标签可以多选，但每个标签都必须有成立依据，具体判据见 [标注规范](instructions.md)。模态只选真正支持该标签的内容：

- **画面**：动作、物体或可见内容。
- **语音/字幕**：实际听到的话或看到的字幕语义。自动转写需对照原音。
- **环境音**：撞击、爆炸、叫喊等非语言声音。不能因为视频“有声音”就勾选。

理由一句话即可，如“男子连续用拳击打另一人的头部”。不要写“模型判断正确”，不要整段复制机器分析。涉及 F1 等需要核查的类别，理由应简述核验依据；拿不准事实、授权或动机时，不保留缺乏依据的标签。

旧草稿若带有旧版未核实标记，核实后修改理由即可消除该标记；依据不成立就删除，不要为了保存而随意改字。

### 自动保存，然后切换下一条

修改标签、时间、模态或理由后，会自动保存。点击“下一条”“上一条”或左侧其他视频时，程序先等待当前修改保存成功，再切换；无需选择“进行中 / 已完成 / 无风险”或勾选观看状态。

顶部显示“已保存”后，改动已写到本机。若保存失败，页面留在当前视频并保留修改；如果时间框格式错误，也会留在原视频，请先改正。

也可点顶部“保存”或按 Ctrl/⌘+S 立即保存当前记录；即使没有改动，也可这样保存一份当前草稿。只打开视频又离开、没有编辑或主动保存时，不会新建人工记录。

**保存只记录修改，不等于确认整片已完成或无风险。** 请仍按分配范围完整观看、补充漏报；只保留有明确依据的片段。视频无法完整观看时，把编号和故障告诉负责人，不要因没有看到内容就下无风险结论。最终有效结果由专家复核。

## 4. 专家：收齐两份结果后裁决

两位标注员在各自电脑独立工作，结果不会自动同步。收齐 A1、A2 的完整文件夹，先备份，再放入专家电脑的：

```text
.annotation-work/desktop-quality_review_20260914/annotations/A1/
.annotation-work/desktop-quality_review_20260914/annotations/A2/
```

三人必须使用同一任务版本。不要修改版本字段或覆盖已有结果来绕过冲突。然后运行：

```bash
python annotate.py --annotator EXPERT
```

1. 点击播放器下方“两人对比”，查看两位标注员保存的记录。普通自动保存记录可能仍有未填写项，不能据此当作两人已完整确认；专家需要逐项核查。缺少任一人的记录时可以保存草稿，但不能完成最终裁决。
2. 点击“以 A1/A2 的片段作为本次裁决起稿”。它会替换当前专家草稿，操作前确认没有需要保留的修改；两份人工原件不变。
3. 用同一套编辑栏核对标签、模态、理由与分秒边界。人工起稿的理由会保留，机器原文仍在旁边独立显示。
4. 完整复看视频，处理分歧，也检查两人共同接受的误报和共同遗漏。时间重叠度只是局部对比，不是整体标注质量分数。
5. 在“两人对比”末尾填写简短裁决说明。专家的日常修改同样自动保存；完整复看、核对两份来源后，点击“保存最终裁决”并确认。它会检查最终片段的必填信息和两份来源版本，随后生成正式裁决。

如果人工来源发生变化，重新加载并核对最新结果。旧来源对应的专家结果不能直接当作最终版本。专家完成状态仍须通过双人来源与版本校验；最终导出由负责人处理。

## 5. 暂停、交接与常见问题

人工记录及修订历史保存在 `.annotation-work/desktop-quality_review_20260914/annotations/你的代号/`。交回自己的整个代号文件夹，不要上传到公开 GitHub。文件管理器中可能需要开启“显示隐藏文件”。

离开前确认保存，再关闭网页并在终端按 Ctrl+C。下次进入同一目录、使用同一代号启动即可继续。删除或搬移仓库前先备份 `.annotation-work/`。

| 问题 | 处理方法 |
|---|---|
| 本地网页打不开 | 保持 Python 终端运行，打开它打印的完整地址；端口可能自动改变 |
| 更新后仍是旧界面或提示 404 | 先停止并重新运行 Python，再强制刷新网页；只刷新网页不会更新后台程序 |
| 视频 502、黑屏或只有声音 | 检查电脑到 Hugging Face 的网络及浏览器兼容性，保留草稿并把视频编号告知负责人 |
| 转写缺失或 partial | 以实际音轨为准，缺失转写不代表没有语音或没有风险 |
| 时间显示红色提示 | 使用 `分:秒`，核对秒数小于 60、起点早于终点且不超过片长 |
| 点击下一条没有切换 | 查看顶部保存报错和时间框错误；保存成功、时间有效后再切换，不需要填写进度 |
| 保存失败、版本或修订冲突 | 先点击顶部“备份本视频”，不要立即刷新；检查是否多个标签页同时编辑，再联系负责人核对最新记录 |
| 删除误报后仍见机器理由 | 机器原文是只读参照；以人工片段列表和保存状态确认结果 |

反馈时说明代号、视频编号、操作步骤和报错。两人不要共用代号或相互复制答案；分歧交专家裁决。
